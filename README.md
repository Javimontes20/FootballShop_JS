**🏆 FootballShop JS**

FootballShop JS es una simulación de una tienda de artículos de fútbol desarrollada con JavaScript. Permite a los usuarios navegar por una lista de productos, añadir y eliminar artículos de un carrito de compras interactivo, y ver el precio total actualizado en tiempo real.

**🚀 Características**

✅ Lista de productos disponibles para la compra.

✅ Sistema de carrito interactivo para añadir y eliminar productos.

✅ Actualización automática del precio total según los productos añadidos.

✅ Diseño responsivo utilizando Flexbox y CSS Grid para una mejor experiencia de usuario en dispositivos móviles y de escritorio.

**🖥️ Tecnologías utilizadas**

- HTML5

- CSS3 (Flexbox y Grid)

- JavaScript (Vanilla)

**🛠️ Cómo usar**


Abre la tienda y navega por la lista de productos disponibles.

Haz clic en "Añadir al carrito" para agregar productos.

El precio total se actualizará automáticamente.

Puedes quitar productos del carrito haciendo clic en "Eliminar".

¡Completa tu compra o sigue explorando!
